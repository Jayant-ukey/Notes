# Que - What is agile and what is SDLC.

### ✅ Interview-Ready Answer (Agile and SDLC)

In real-world software development, **SDLC (Software Development Life Cycle)** and **Agile** are two important concepts that define how we build and deliver software in a structured and iterative way.

---

# 🔹 1. What is SDLC?

**SDLC (Software Development Life Cycle)** is a **structured process used to design, develop, test, and deploy software systematically**.

It defines the complete flow of software development from requirement gathering to maintenance.

---

## 📌 Phases of SDLC:

1. **Requirement Gathering**

   * Understand business needs

2. **Design**

   * High-level and low-level design (HLD/LLD)

3. **Development**

   * Writing code (Spring Boot services, APIs, etc.)

4. **Testing**

   * Unit testing, integration testing

5. **Deployment**

   * Deploying to production (CI/CD, Docker, Kubernetes)

6. **Maintenance**

   * Bug fixes, enhancements, performance improvements

---

## ✔ Key Idea:

👉 SDLC is a **process framework** that ensures software is built in a disciplined and predictable way.

---

# 🔹 2. What is Agile?

**Agile is a software development methodology** based on **iterative and incremental delivery**, where requirements and solutions evolve through collaboration.

Instead of building the entire system at once, Agile focuses on **small, continuous deliveries (sprints)**.

---

## 📌 Key Features of Agile:

* Work is divided into **sprints (2–3 weeks typically)**
* Continuous feedback from stakeholders
* Frequent releases of working software
* Collaboration between developers, testers, and business teams
* Adaptive to changing requirements

---

## 📌 Example in Real Projects:

In a Spring Boot microservices project:

* Sprint 1 → User Service APIs
* Sprint 2 → Order Service APIs
* Sprint 3 → Payment integration

✔ Each sprint delivers a working feature incrementally.

---

# 🔹 3. SDLC vs Agile (Important Interview Comparison)

| SDLC (Traditional)         | Agile                          |
| -------------------------- | ------------------------------ |
| Sequential process         | Iterative process              |
| Heavy documentation        | Lightweight documentation      |
| Fixed requirements         | Changing requirements accepted |
| Late delivery              | Continuous delivery            |
| Waterfall model often used | Sprint-based development       |

---

# 🔹 4. Relationship Between Agile and SDLC

👉 Agile is actually a **type of SDLC model**

Other SDLC models include:

* Waterfall
* Spiral
* V-Model
* Agile (most widely used today)

---

# 🔹 5. Agile in Real Microservices Projects

In real Spring Boot microservices development:

* Each microservice is delivered incrementally
* CI/CD pipelines support continuous delivery
* Frequent releases per sprint
* Feedback is quickly incorporated

✔ Agile fits very well with microservices architecture because both support **independent and incremental development**.

---

# 📌 Key Points Interviewers Look For

* SDLC is a structured software development process
* Agile is an iterative SDLC model
* Agile uses sprints and continuous delivery
* Agile supports changing requirements
* Microservices align well with Agile methodology
* Real-world delivery mindset (not just theory)

# 🧾 Short Answer (40–50 seconds)

“SDLC, or Software Development Life Cycle, is a structured process used to design, develop, test, and deploy software in phases like requirement gathering, design, development, testing, deployment, and maintenance. Agile is a type of SDLC model that follows an iterative and incremental approach where development is done in small cycles called sprints. In Agile, requirements can evolve, and we deliver working software frequently with continuous feedback. Compared to traditional models like Waterfall, Agile is more flexible and faster. In modern microservices projects, Agile is widely used because it supports continuous delivery and independent service development.”
