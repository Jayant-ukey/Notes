# 1. What is Google Cloud Storage?

**Ans:**  
Google Cloud Storage is a secure, highly durable, and scalable object storage service within Google Cloud for developers and enterprises to store unstructured data, such as audio, video, and backups.

## How It Works

- **Buckets:**  
  Data is stored in buckets, which are containers associated with a specific project, allowing for granular permission control.

- **Objects:**  
  Files, known as objects, are stored within these buckets.

- **Data Organization:**  
  Supports folder structures within buckets to simulate file systems, including managed folders for simplified access control.

## Use Cases

- **Cloud Storage for Apps:**  
  Storing media, content, and user-generated data.

- **Backup & Recovery:**  
  Using Nearline/Archive classes for cost-effective backups.

- **Data Analytics:**  
  Serving as a data lake for large-scale analytics.

## Pricing

Google Cloud Storage charges are based on:
- The storage class used  
- The amount of data stored  
- Data access frequency  
- Network egress  

It offers a cost-effective solution compared to on-premise storage, especially for long-term storage.
